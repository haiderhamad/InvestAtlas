# README images

The project owner supplied both English-language illustrations as finished PNGs (1122 × 1402 pixels each). They are reproduced as supplied. Open the originals to inspect chart labels and dates.

- [InvestAtlas across every screen](investatlas-across-screens.png) shows desktop and phone layouts, including an ETF quote and precious-metal charts.
- [Mobile-first market clarity](investatlas-mobile-charts.png) pairs the five-year gold view in the dark theme with the one-year silver view in the light theme.

The displayed observations are historical. The ETF view credits Yahoo Finance. Metal spot prices come from Gold API, with ECB reference FX for EUR conversion. Historical metal closes are provided by [Data by Standard Bullion](https://standardbullion.com/market-data).

## Wordmark and notices

The [InvestAtlas wordmark](investatlas-logo.svg) uses the same two original IA strokes as the [app icon](../../public/app-icon.svg). The monogram and wordmark layout are project artwork under Apache-2.0.

Market observations, third-party marks and rendered fonts retain their own terms. The source license and asset provenance are described in [Licensing](../../LICENSING.md).
